🎣 Phishing Attack Anatomy

📧
1
The Bait
Attacker sends a fake email/message pretending to be from 1voucher.co.za, MetaMask, or a trusted service.
🔗
2
The Hook
Message contains a urgent link: "Verify your account now!" or "Your voucher is expiring!"
🌐
3
The Fake Site
Link goes to a site that looks real but has a subtle URL difference (e.g., 1voucher-secure.com instead of 1voucher.co.za).
📝
4
The Theft
User enters login details or seed phrase—attacker captures them instantly.
💸
5
The Drain
Attacker uses stolen credentials to empty the account before the user realizes.

🔁 Reentrancy Attack (Smart Contract)

🏦
1
The Vulnerable Contract
A smart contract has a withdraw() function that sends ETH before updating the user's balance.
🐍
2
The Malicious Contract
Attacker creates a contract whose fallback function calls withdraw() again.
🔄
3
The First Call
Attacker calls withdraw(). Contract sends ETH... then calls attacker's fallback before updating balance.
🔁
4
The Reentrancy Loop
Fallback function calls withdraw() again—contract sends more ETH because balance hasn't been updated yet.
💸
5
The Drain
This repeats until the contract is empty—classic reentrancy exploit (like the DAO hack).

📋 Clipper Malware (Clipboard Hijacker)

💻
1
The Infection
User downloads infected software (fake wallet app, cracked tool, etc.) containing clipper malware.
📋
2
The Hijack
Malware monitors clipboard for cryptocurrency addresses (long strings of letters/numbers).
🔄
3
The Swap
When user copies a legitimate address, malware silently replaces it with attacker's address.
📋
4
The Paste
User pastes what they think is the correct address—but it's now the attacker's.
💸
5
The Theft
Transaction goes to attacker instead of intended recipient—funds are gone.

🛡️ How to Defend Against This

For Phishing: Always check URLs carefully. Bookmark legitimate sites. Never enter credentials from links in messages.

For Reentrancy: Use the "checks-effects-interactions" pattern: update state before sending funds.

For Clippers: Always double-check pasted addresses by comparing first and last characters with the original.

Remember: Your vigilance is the strongest defense.
